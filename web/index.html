Aufgaben wie im Testat, jedes Mal neu ausgewürfelt, mit Lösungen. Sie bekommen ein LaTeX-Projekt als ZIP, das Sie in Overleaf öffnen.

Was soll auf das Blatt?

Welches Testat möchten Sie üben? Das Blatt enthält alle Aufgaben, die auf der Karte stehen.

    Aufgaben

    Gleiches Testat (bzw. gleiche eigene Auswahl) und gleicher Seed ergeben genau dasselbe Blatt. Den Seed eines Blatts sehen Sie nach dem Erzeugen unter „Fertig“.

    Fertig

    ZIP herunterladen

      So öffnen Sie das ZIP in Overleaf

      1. In Overleaf New Project → Upload Project wählen und das ZIP hochladen.
      2. main.tex enthält die Aufgabenblätter.
      3. Für die Lösungen im Menü unter Main document die Datei loesungen.tex wählen und neu übersetzen.
